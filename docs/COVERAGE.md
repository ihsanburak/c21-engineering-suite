# Calculation coverage — 1.0 Classic Edition

**138 interactive calculation/utility targets** across **64 documented model/workflow families**. One target is a formatting utility; alternate solved variables are counted as targets, not independent physical families. Shared menu links are not new calculations.

| Area | Examples |
|---|---|
| Basic electronics | Ohm outputs, electrical power, resistor networks, dividers, Kirchhoff helpers, LED resistor, capacitor energy and RC models |
| RLC | Reactance, resonance and inverse design, ideal series impedance/magnitude/phase, RC/RL time constants |
| Power/battery | Charge/energy units, runtime estimate, average duty power, LDO loss, converter efficiency and resistor dissipation |
| RF/filter/antenna | dBm/mW, gains/losses, noise, link budget, reflection/VSWR/return loss, matching, filters, wavelength, Fresnel and propagation models |
| PCB | Copper trace/via resistance, advisory trace current, copper thickness, zero-thickness microstrip and propagation |
| Measurement/VNA/tools | Manual S-parameter data calculations, mismatch/delivered power, tolerances, four-reading statistics/uncertainty, preferred values and numeric SMD codes |
| LoRa | Symbol timing/rate, nominal bit rate, code relationships, packet/preamble/payload timing and symbols, user-entered duty budget, packet count and battery-draw energy |
| Handbook | Formula/symbols/units, purpose, laboratory usage/instruments, assumptions, worked example and common mistakes for every implemented target |

Every target uses real editable values and explicit unit conversion to/from SI, with domain/error handling. Compact formulas use Formula Mode; long/discrete tools use List Mode as documented. All data entry is manual; instrument names describe laboratory context rather than hardware integration.

See [the detailed target inventory](CALCULATION_INVENTORY.md), [known limitations](KNOWN_LIMITATIONS.md) and [validation](VALIDATION.md). Host checks and independent numerical references do not imply every physical model or every real input has been verified.
